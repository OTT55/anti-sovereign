# Decisions — why Sovereign Edit is built the way it is

Every meaningful choice gets a short numbered file here (an **ADR** —
*Architecture Decision Record*): what we chose, why, and the honest trade-off.
So the reasoning is never lost, and changing a decision means adding a new record
rather than erasing the old thinking.

Each has four parts: **Context**, **Decision**, **Why**, **Trade-off**.
